# AeroDeck

A small, responsive dashboard with a soft Frutiger Aero-inspired visual style.

## Features

- Live clock using the browser's local time
- Date and time-aware greeting
- Random idea generator
- Responsive layout
- Keyboard-visible focus styles and reduced-motion support
- No frameworks, build tools, external fonts, or runtime dependencies

## Run it

Open `index.html` in any modern browser. That's it.

For local development, you can also serve this directory with any static file server.

## Files

- `index.html` — semantic page structure
- `style.css` — layout, visual design, and responsive rules
- `app.js` — clock, greeting, and idea generator

## Privacy

AeroDeck does not make network requests, use cookies, or store data. Everything runs locally in the browser.
