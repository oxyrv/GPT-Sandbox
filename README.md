## Repository guidelines

- Keep the repository public.
- Never commit credentials, tokens, private data, or other secrets.
- Prefer small, self-contained projects with clear documentation.
- Avoid destructive Git operations and unnecessary dependencies.
- Keep code readable and explain non-obvious decisions.

Each project should include its own README with setup and usage instructions.
